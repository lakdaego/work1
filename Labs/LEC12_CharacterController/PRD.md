# Character Controller AUTORUN — 제품 요구사항 문서 (PRD)

## 1. 문서 정보

- **상태:** 구현 전 요구사항
- **대상 프로그램:** `boy.py`
- **기술:** Python, pico2d, transitions
- **기준 동작:** 현재 IDLE, RUN, SLEEP 상태와 키보드 입력 처리

## 2. 제품 개요

기존 캐릭터 컨트롤러에 **AUTORUN** 상태를 추가한다. 사용자가 IDLE 상태에서 `a` 키를 누르면 캐릭터는 현재 방향으로 자동 이동을 시작하고, 화면의 좌우 경계에 도달할 때마다 방향을 바꾼다. AUTORUN 중 캐릭터는 기존 RUN보다 빠르고 1.5배 크게 표시된다. 시작 후 5초가 지나면 자동 이동을 멈추고 IDLE 상태로 복귀한다.

## 3. 목표와 범위

### 목표

1. IDLE에서 `a` 키 한 번으로 자동 왕복 이동을 시작한다.
2. 캐릭터가 화면 좌우 경계를 벗어나지 않게 이동 방향을 자동으로 반전한다.
3. AUTORUN의 속도와 표시 크기를 기존 RUN과 구분되게 한다.
4. AUTORUN 진입 후 5초가 지나면 입력 없이 IDLE로 복귀한다.
5. 기존 IDLE, 수동 RUN, SLEEP 동작을 유지한다.

### 범위에 포함

- 상태 머신에 AUTORUN 상태와 필요한 상태 전이 추가
- IDLE 상태에서의 `a` 키 입력 처리
- 좌우 경계 반전 및 AUTORUN 전용 이동 속도·렌더링 크기
- 5초 타이머에 따른 IDLE 복귀와 타이머 초기화

### 범위에 포함하지 않음

- 캐릭터 이미지나 스프라이트 시트 변경
- 점수, 적, 사운드, 새 UI 추가
- AUTORUN 지속 시간·속도·크기를 조정하는 설정 기능
- 기존 RUN 및 SLEEP 동작의 재설계

## 4. 기준 동작과 결정 사항

| 항목 | 요구사항 |
|---|---|
| 일반 RUN 이동량 | 현재 기준인 업데이트당 5px |
| AUTORUN 이동량 | 업데이트당 10px (일반 RUN의 2배) |
| 일반 캐릭터 표시 크기 | 100 × 100px |
| AUTORUN 표시 크기 | 150 × 150px (가로·세로 각각 1.5배) |
| 기존 이동 좌표 경계 | 현재 캐릭터 중심 기준 x=50~750 |
| AUTORUN 이동 경계 | 800px 화면과 150px 표시 크기를 고려해 캐릭터 중심 x=75~725 |
| AUTORUN 지속 시간 | 진입 시점부터 5초 |
| 시간 측정 | 프레임 수가 아닌 단조 증가 시계의 경과 시간 |

속도 기준은 현재 구현의 업데이트당 이동량을 바탕으로 정한다. 업데이트 주기가 달라져도 AUTORUN 지속 시간이 5초가 되도록 시간 제한은 경과 시간으로 판정한다.

## 5. 사용자 시나리오

1. 프로그램을 실행하면 캐릭터가 IDLE 상태로 표시된다.
2. 사용자가 `a` 키를 누르면 AUTORUN이 시작되며, 캐릭터는 현재 바라보는 방향으로 이동한다.
3. 캐릭터는 150 × 150px 크기로 표시되고, 일반 RUN보다 빠르게 움직인다.
4. 캐릭터 중심이 화면 좌우의 AUTORUN 경계에 닿으면 화면 밖으로 나가지 않고 바라보는 방향과 이동 방향을 반전한다.
5. AUTORUN 시작 후 5초가 지나면 캐릭터는 이동을 멈추고 기존 크기의 IDLE 포즈로 돌아간다.
6. 다시 IDLE이 된 뒤에는 `a` 키로 AUTORUN을 새로 시작할 수 있다.

## 6. 기능 요구사항

### FR-01: AUTORUN 진입

- `a` 키의 `KEYDOWN` 이벤트가 들어왔을 때 현재 상태가 IDLE이면 AUTORUN으로 전이한다.
- 키를 누르고 있는 동안 반복 발생하는 `KEYDOWN` 이벤트가 지속 시간을 재시작하거나 속도를 누적 변경하지 않는다.
- RUN 또는 SLEEP 상태에서 `a`를 누르면 AUTORUN을 시작하지 않는다.
- AUTORUN 시작 시각을 기록하고, 기존 `face_dir`을 초기 이동 방향으로 사용한다.

### FR-02: 자동 이동과 경계 반전

- AUTORUN 상태에서는 키 입력 없이도 매 업데이트마다 캐릭터가 현재 방향으로 이동한다.
- 일반 RUN의 업데이트당 5px를 기준으로 AUTORUN은 업데이트당 10px 이동한다.
- 화면 너비는 현재 기본 캔버스의 800px를 기준으로 한다. 150px 크기 캐릭터가 완전히 보이도록 중심 위치를 x=75~725 범위로 제한한다.
- 캐릭터가 좌우 경계에 도달하면 x 위치를 경계 안에 유지하고 `face_dir`을 반전한다. 다음 업데이트부터 반대 방향으로 이동한다.
- 방향 반전 시 스프라이트도 새로운 방향을 바라보도록 표시한다.

### FR-03: 크기 및 애니메이션

- AUTORUN 중 캐릭터의 너비와 높이는 각각 150px로 표시한다.
- AUTORUN을 벗어나면 표시 크기를 기존 100 × 100px로 복구한다.
- 기존 스프라이트 시트의 RUN 애니메이션을 사용하고, 현재 프레임 진행 방식은 유지한다.

### FR-04: 시간 만료와 IDLE 복귀

- AUTORUN 진입 후 단조 증가 시계 기준 5초가 경과하면 IDLE로 전이한다.
- 만료 시 자동 이동을 중단하고, 일반 IDLE 애니메이션과 기본 표시 크기를 적용한다.
- IDLE 복귀 시 `idle_since`를 현재 시각으로 재설정한다. 따라서 AUTORUN 직후 IDLE에 진입하자마자 기존 IDLE 타이머 조건으로 SLEEP에 들어가지 않는다.
- AUTORUN 중에는 IDLE의 SLEEP 타이머를 진행시키지 않는다.

### FR-05: 다른 입력과 기존 상태 호환

- AUTORUN 중 방향키 입력은 자동 이동 방향을 덮어쓰거나 AUTORUN을 수동 RUN으로 전환시키지 않는다.
- AUTORUN 중 `a` 입력은 현재 실행 중인 5초 타이머를 다시 시작하지 않는다.
- 기존 IDLE에서 좌우 방향키를 이용한 RUN 전이 및 키 해제 처리, SLEEP 진입·깨우기 동작은 변경하지 않는다.
- 창 닫기 및 ESC 종료 동작은 AUTORUN 중에도 기존과 동일하게 동작한다.

## 7. 상태 모델

상태 전이는 다음과 같다.

| 현재 상태 | 입력/조건 | 다음 상태 |
|---|---|---|
| IDLE | 좌/우 방향키 누름 | RUN |
| IDLE | `a` 키 누름 | AUTORUN |
| IDLE | 기존 IDLE 타이머 만료 | SLEEP |
| RUN | 모든 방향키 해제 | IDLE |
| SLEEP | SPACE 키 누름 | IDLE |
| AUTORUN | 진입 후 5초 경과 | IDLE |

AUTORUN 중 화면 경계 도달은 상태 전이가 아니라 방향 반전으로 처리한다. AUTORUN 진입과 종료 시 각각 시작 시각 및 IDLE 타이머를 초기화한다.

## 8. 인수 기준

1. IDLE에서 `a` 키를 누르면 AUTORUN 상태가 되고, 캐릭터가 입력 없이 이동한다.
2. AUTORUN 이동량은 일반 RUN 이동량의 2배이며, 기준값은 업데이트당 10px 대 5px다.
3. AUTORUN 중 그려지는 캐릭터 크기는 정확히 150 × 150px이며, IDLE 복귀 후에는 100 × 100px다.
4. 좌우 경계에 도달한 뒤 캐릭터 중심 위치는 x=75~725 범위를 벗어나지 않고 이동 방향과 스프라이트 방향이 반전된다.
5. AUTORUN 시작 후 5초가 경과하면 자동으로 IDLE로 전이되고 추가 이동이 없다.
6. AUTORUN 종료 직후 IDLE 타이머가 새로 시작되어, 이전 타이머 값만으로 즉시 SLEEP 상태가 되지 않는다.
7. RUN·SLEEP 진입과 복귀, 키보드 입력, ESC 및 창 닫기 동작이 AUTORUN 추가로 인해 손상되지 않는다.
